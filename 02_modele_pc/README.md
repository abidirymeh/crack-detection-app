# Dossier 02_modele_pc - Code et modeles 
 
## Structure 
 
- `scripts/` : Tous les scripts Python 
  - `detection_fissures/` : Scripts pour la partie 1 
  - `analyse_materiaux/` : Scripts pour la partie 2 
- `results/` : Graphiques et resultats 
- `models/` : Modeles finaux 
  - `mobilenetv3_fissures.tflite` : Modele pour mobile 
- `archive/` : Anciens fichiers 
 
## Utilisation 
 
1. Activer l'environnement : `venv\Scripts\activate` 
2. Installer dependances : `pip install -r requirements.txt` 
3. Executer les scripts dans l'ordre
